# Web App
Visit the **web app** at https://wow-icons.streamlit.app!

# Setup
You can find the package, [here](https://pypi.org/project/i8-downloader/).
```
pip3 install i8-downloader
```

# Usage
```bash
i8-downloader # manul setup
i8-downloader https://img.icons8.com/stickers/256/000000/star.png # automatic setup
```

# Local Chrome extension

This repository also includes a Chrome extension for personal, local use.
It adds a neon **Quick PNG 512** button next to the standard Download button in
the Icons8 icon detail panel.  

[![Watch the 22-second demo on Loom](https://img.shields.io/badge/Watch_demo-22_seconds-625DF5?style=for-the-badge&logo=loom)](https://www.loom.com/share/7d6a7101d80e465992c1ff11a60c9f97)

## Install the extension

1. Open `chrome://extensions` in Chrome.
2. Enable **Developer mode**.
3. Click **Load unpacked**.
4. Select the [`extension`](extension) directory from this repository.
5. Open or reload Icons8, then select an icon to display the
   **Quick PNG 512** button.

More details, including how to change the download size, are available in
[`extension/README.md`](extension/README.md).
